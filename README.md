# مدونة تسنيم — موقع عربي ثابت (RTL)

موقع ثابت جاهز للإنتاج ويعمل بكفاءة عالية: اعتمد كليًا على HTML + CSS + JS فقط، بدون الحاجة لأي أدوات بناء أو تعقيدات برمجية.

---

## 📁 قائمة الملفات ووظائفها

| الملف | الوظيفة الشاملة |
|---|---|
| `index.html` | الصفحة الرئيسية: تتضمن محرك البحث اللحظي، التصفية حسب التصنيف، وترقيم الصفحات[cite: 9]. |
| `post.html?id=...` | صفحة عرض المقال المنفرد: تحتوي على نص المقال، أزرار المشاركة، وقائمة بمقالات ذات صلة[cite: 9]. |
| `category.html?c=` / `?tag=` | صفحة التصنيفات والوسوم: تعثر على المقالات المفلترة حسب التصنيف أو الوسم [#][cite: 9]. |
| `downloads.html` | صفحة التحميلات: تضم قائمة ببرامج وألعاب مجانية مع خيار البحث والتصفية[cite: 9]. |
| `scripts.js` | ملف المنطق البرمجي: يحوي كافة بيانات المقالات والتحميلات (`POSTS`, `DOWNLOADS`)[cite: 9]. |
| `styles.css` | ملف التنسيقات البصرية والهوية: مصمم وفق أسلوب (Mobile-first) لتدعم الشاشات الذكية بشكل ممتازة[cite: 9]. |
| `feed.xml` | ملف موجز الأخبار (RSS) لإتاحة متابعة المقالات عبر قارئات التغذية[cite: 9]. |
| `sitemap.xml` | خريطة الموقع لمساعدة محركات البحث مثل Google على فهرسة الصفحات[cite: 9]. |
| `robots.txt` | ملف توجيه عناكب البحث وتحديد رابط خريطة الموقع[cite: 9]. |
| `deploy.sh` | سكريبت الرفع السريع لتنفيذ أوامر الرفع بضغطة واحدة[cite: 9]. |

---

## 💻 تجربة الموقع محلياً على جهازك

لتشغيل الموقع ومعاينته على حاسوبك قبل الرفع:

```bash
# شغل سيرفر محلي باستخدام Python 3
python3 -m http.server 8000

# ثم افتح المتصفح على الرابط: http://localhost:8000
```[cite: 9]

## 🚀 النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا (Repository) باسم `arabic-blog` على حسابك وارفع الملفات[cite: 9]:
   ```bash
   git init && git add -A && git commit -m "أول نشر لمدونة تسنيم"
   git branch -M main
   git remote add origin [https://github.com/USERNAME/arabic-blog.git](https://github.com/USERNAME/arabic-blog.git)
   git push -u origin main
   ```[cite: 9]

2. داخل مستودعك على GitHub اختر: **Settings → Pages → Source: GitHub Actions**[cite: 9].
3. سيتولى الملف `.github/workflows/deploy.yml` نشر الموقع تلقائيًا مع كل عملية رفع[cite: 9, 14].

---

## 🌐 النشر على Netlify

* **طريقة السحب والإسقاط:** افتح الرابط [Netlify Drop](https://app.netlify.com/drop) واسحب مجلد المشروع كاملاً[cite: 9].
* **ربط المستودع (نشر آلي):** اختر `Add new site` ← `Import from GitHub` ← حدد المستودع[cite: 9]. (الإعدادات جاهزة عبر ملف `netlify.toml` ولا يحتاج أي أمر بناء)[cite: 7, 9].

---

## ⚡ النشر والتحديث بضغطة واحدة

بعد إجراء أي تعديل على المقالات أو التصميم، يمكنك الرفع بضغطة زر عبر الملف المساعد:

```bash
./deploy.sh "إضافة مقال جديد"
```[cite: 9]

---

## 📝 كيفية إضافة مقال جديد

1. أضف كائنًا جديدًا يحوي بيانات المقال داخل مصفوفة `POSTS` في ملف `scripts.js`[cite: 9, 11].
2. أضف عنصرًا جديدًا يطابق رابط المقال في ملف `feed.xml` وملف `sitemap.xml` لضمان السيو[cite: 5, 9, 12].

---

## ⚠️ خطوات مهمة قبل إطلاق الموقع رسميًا

* **استبدال اسم المستخدم:** ابحث عن كلمة `USERNAME` في ملفات (`feed.xml`, `sitemap.xml`, `robots.txt`) واستبدلها باسم مستخدم GitHub أو نطاقك الخاص[cite: 5, 9, 10, 12].
* **استبدال الصور:** الصور الحالية تستخدم خدمة Picsum المؤقتة؛ يفضل وضع صورك داخل مجلد `assets/` وتحديث رابط الصورة في `scripts.js`[cite: 9, 11].
